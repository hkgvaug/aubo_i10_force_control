## 1. 供电（先量再插）

| 项目 | 要求 |
|---|---|
| 电压 | **9–24 VDC** |
| 功率 | **< 3 W** |
| 极性 | **蓝线 = 电源 +，白线 = 电源 −** |
| 反接 | **会烧电路板，手册明确警告** |

上电前用万用表确认：

1. 电源适配器空载输出电压在 9–24 V 之间；
2. 适配器极性正确（内正外负或按标签），不要只看插头形状；
3. 蓝/白线与适配器 +/− 对应正确；
4. 断电状态下量一下电源 +/− 之间没有短路。

不要用 USB 转换器的 5 V 给传感器供电，电压不够。

## 2. 7 芯线色定义（手册第 10 页）

方向以**传感器**为参照：

| 序号 | 线色 | 定义 |
|---|---|---|
| 1 | 蓝 Blue | 电源 + |
| 2 | 白 White | 电源 − |
| 3 | 粉 Pink | 422 接收 +（传感器 RX+） |
| 4 | 棕 Brown | 422 接收 −（传感器 RX−） |
| 5 | 黑 Black | 422 发送 +（传感器 TX+） |
| 6 | 灰 Grey | 422 发送 −（传感器 TX−） |
| 7 | 屏蔽 Shielding | 屏蔽/地 |

> 手册表格里第 3 行印的是 “Powder”，应为 **Pink（粉色）**，以实物和图上标注为准。接线前最好用万用表通断档核对一次。

## 3. 与 USB-RS422 转换器的接线

| 传感器 | 转换器 |
|---|---|
| 黑（TX+） | RX+ / R+ / A |
| 灰（TX−） | RX− / R− / B |
| 粉（RX+） | TX+ / T+ |
| 棕（RX−） | TX− / T− |
| 屏蔽 | GND / Shield（按转换器说明） |

**关键点：转换器必须能发送（有 TX 对）。**

传感器不是上电就主动发数据，必须先收到 `48 AA 0D 0A` 才开始 1 kHz 输出。只有 RX 的 2 线 RS485 接收器/只接线不接 TX 的转换器会表现为“完全没数据”。

- 若转换器只有 `R+/R−`，无法启动传感器，需要换成全双工 RS422 转 USB。
- 若接好后 `frames=0`，可以先把黑/灰这一对 TX 线对调试试（RS422 的 A/B 标注有时相反）。
- 电源地与转换器地是否共地按转换器说明书处理；隔离型转换器不要随意短接。

## 4. 上电与检查顺序

1. 断电状态下接好电源和 7 芯线；
2. 转换器插 USB，确认虚拟机认到 `/dev/ttyUSB0`；
3. 给传感器上电（9–24 V）；
4. 先运行探针，不启动 ROS：

```bash
python3 ~/aubo_ws/src/kwr75_ft_sensor/scripts/kwr75_probe.py \
  --port /dev/ttyUSB0 --duration 10 --raw
```

正常输出应类似：

```text
raw[1]: 48 AA B0 75 1C C1 9B 3F ED C0 AE 5C F0 40 D4 B5 2D BE 5F 55 99 3E 7C 1A B0 BB 0D 0A
frames=2001  rate=1000.2 Hz  F=(  -0.02   -0.01    0.00) N  M=(  0.000   0.000   0.000) Nm
Stopped. frames=10012 bad_tail=0 bad_payload=0 discarded_bytes=0
```

理想情况下 `rate` 接近 1000 Hz，`bad_tail`/`discarded_bytes` 接近 0。

上面显示的是**未清零**的原始值。装了工具或传感器有零点偏置时，Fz 不为 0 是正常的；探针能稳定出帧、数值平稳即可。之后在 ROS 里调用 `/ft_sensor/tare` 去掉偏置。

## 5. 探针没数据时的排查顺序

1. 电源是否 9–24 V、极性是否正确（**先断电再改线**）；
2. 转换器是否有 TX 对，且 TX 接到了传感器 RX（粉/棕）；
3. 黑/灰 TX 对是否接反；
4. 波特率是否 460800、8N1、无校验；
5. 虚拟机是否真的把转换器 USB 透传进去（`ls -l /dev/ttyUSB*`、`dmesg | tail`）；
6. 当前用户是否在 `dialout` 组；
7. 是否已装 udev 规则并把 `latency_timer` 设为 1。
